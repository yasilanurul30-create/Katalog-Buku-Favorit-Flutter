# Katalog Buku Favorit — Flutter

Proyek sederhana untuk tugas Laporan 1 Flutter/Dart.

## Cara membuka di VS Code

1. Ekstrak ZIP ini.
2. Buka folder `katalog_buku_flutter` di VS Code.
3. Buka Terminal > New Terminal.
4. Jalankan `flutter doctor` untuk memeriksa instalasi.
5. Jalankan `flutter create .` di folder proyek untuk membuat folder platform yang diperlukan.
6. Jalankan `flutter pub get`.
7. Jalankan `flutter run -d chrome` untuk membuka aplikasi di Chrome.

Jika perintah `flutter create .` menanyakan apakah file akan ditimpa, jangan menimpa `lib/main.dart` atau `pubspec.yaml` yang sudah disediakan.

## File utama

- `lib/main.dart`: kode aplikasi.
- `pubspec.yaml`: konfigurasi proyek Flutter.

## Catatan tugas

Ganti nama/identitas sesuai kebutuhan tugas. Pastikan topik Katalog Buku Favorit tidak sama dengan topik mahasiswa lain. Ambil screenshot dari aplikasi yang benar-benar berjalan dan tambahkan watermark `NIM_NAMA` sesuai instruksi dosen.
